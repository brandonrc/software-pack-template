# Maintainers

This file is the authoritative list of maintainers for this repository. Nothing else is: not the governance repository, not the website, not the GitHub team list.

Maintainers hold write access here, decide this repository's features, releases, dependencies, and, for a pack, its maturity level. See the [Nebari governance](https://github.com/nebari-dev/governance/blob/main/GOVERNANCE.md#teams-and-roles) for what that authority covers and what it does not.

| Name | GitHub | Role |
| ---- | ------ | ---- |
| _Your name_ | [@your-handle](https://github.com/your-handle) | Maintainer |

The `owner` field in `pack-metadata.yaml` names the single most accountable maintainer. Keep the two consistent.

## Becoming a maintainer

Existing maintainers add new ones, on the basis of a record of regular, valuable contributions to this repository. Nominate someone, including yourself, by opening an issue here.

## Stepping back

Say so, in an issue or privately to the other maintainers. Update this file and `pack-metadata.yaml` in the same change so the accountable person is never ambiguous.
