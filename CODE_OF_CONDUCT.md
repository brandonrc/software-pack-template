# Code of Conduct

This project follows the Nebari Code of Conduct.

The full text, including what is expected, what is unacceptable, and how enforcement works, is in the governance repository:

**[Nebari Code of Conduct](https://github.com/nebari-dev/governance/blob/main/CODE_OF_CONDUCT.md)**

## Reporting

To report an incident, use [this form](https://forms.gle/PFHmsMUiu12qJwWV7_), which reaches the [Code of Conduct committee](https://github.com/nebari-dev/governance/blob/main/code-of-conduct/coc_enforcement.md#the-code-of-conduct-committee).

If you would rather not use the form, or the incident involves a member of the committee, you can contact any committee member directly using the addresses in the [enforcement manual](https://github.com/nebari-dev/governance/blob/main/code-of-conduct/coc_enforcement.md).

Reports are kept confidential.
